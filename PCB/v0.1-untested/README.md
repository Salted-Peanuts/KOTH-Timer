# KOTH Timer PCB v0.1 - Untested

This folder contains the first PCB design for the KOTH Timer.

## Status

**Untested hardware.**

This PCB has not yet been manufactured or validated. It is provided so people can inspect the design, review the routing, check the schematic, and manufacture it at their own risk.

## Important Notes

* Check all wiring against the schematic before ordering.
* Check Arduino Nano ESP32 pin assignments against the firmware.
* Check battery polarity and power routing carefully.
* Check display, button, LED, and battery indicator connections.
* This PCB may contain mistakes.
* Do not treat this as a confirmed production-ready design.

## Recommended Use

This PCB is intended for review and testing.

If you manufacture it, inspect the board carefully before installing components or connecting a battery.

## Version

PCB version: `v0.1-untested`
