# Hardware Files

This folder contains the hardware documentation for the KOTH Timer prototype.

## BOM

The bill of materials is available in two formats:

- `docs/BOM.xlsx` - formatted Excel version
- `docs/BOM.csv` - simple GitHub-friendly version

## Schematic

The schematic is only available in PDF for now:

- `docs/Wiring_schematic.pdf` - printable schematic exported from KiCad

## Notes

This hardware is based on the tested prototype version.

Check all wiring carefully before powering the device. Some parts may need different resistor values or pin assignments depending on the exact components used.
